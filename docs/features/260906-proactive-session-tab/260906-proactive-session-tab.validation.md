## 验证说明

- 验证对象（2026-09-06 定稿版）：
  - 对话页「主动唤醒」tab（会话级闹钟/每闹钟历史/编辑），**无偏好体系**

- 环境/前置条件：dsh web GUI（http://127.0.0.1:4175）；插件 lib/ 已重新 build 并同步到安装镜像，dsh 已重启；`camoufox` 浏览器可交互（或用户自备浏览器）
- 注意：心跳预设按钮、全局/会话级间隔抖动偏好、会话参与开关**已删除**——验证时这些不应再出现
